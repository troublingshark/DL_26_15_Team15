# Wafer Defect Analysis Service

## 프로젝트 개요

YOLOv8 Segmentation 모델을 활용해 웨이퍼 이미지에서 결함을 자동으로 검출하고, 여러 이미지의 분석 결과를 종합해 결함 분포와 confidence 경향을 시각화하는 Streamlit 기반 서비스입니다.

단순히 모델을 실행하는 데 그치지 않고, 여러 장의 웨이퍼 이미지를 한 번에 업로드하면 class별 통계 집계, 그래프 시각화, 보고서 자동 생성까지 이어지는 분석 서비스 형태로 구성했습니다.

---

## 개발 목적

- 웨이퍼 이미지에서 결함 종류와 위치를 자동으로 검출
- 여러 이미지 분석 결과를 결함 class별로 집계하고 비교
- 검출 결과를 그래프와 표로 시각화
- CSV, ZIP, TXT 형태로 결과를 저장·다운로드할 수 있도록 구성
- 교수님께서 요구하신 **"모델 활용 서비스 구축"** 방향에 맞게 확장한 프로젝트입니다.

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| 다중 이미지 업로드 | 여러 장의 웨이퍼 이미지를 한 번에 업로드 |
| 결함 검출 | YOLOv8-seg 모델로 결함 위치·종류 자동 검출 |
| 이미지 비교 | 원본 이미지와 검출 결과 이미지를 나란히 확인 |
| 이미지별 결과 표 | 각 이미지에서 검출된 결함 정보를 표로 제공 |
| class별 요약 표 | 결함 종류별 개수, 비율, confidence 통계 집계 |
| 통계 그래프 | class별 결함 개수 / 비율 / 평균 confidence 막대그래프 |
| CSV 다운로드 | 전체 검출 결과 및 class별 요약 CSV 저장 |
| ZIP 다운로드 | 결과 이미지 전체를 ZIP 파일로 다운로드 |
| TXT 보고서 | 분석 결과를 요약한 텍스트 보고서 자동 생성 및 다운로드 |

---

## 기술 스택

- **모델**: YOLOv8-seg (Ultralytics)
- **UI**: Streamlit
- **이미지 처리**: OpenCV, Pillow
- **데이터 분석**: Pandas, NumPy

---

## 실행 방법

```bash
# 가상환경 활성화 (Windows)
.venv\Scripts\activate

# 앱 실행
streamlit run app.py
```

브라우저에서 `http://localhost:8501` 로 접속하면 서비스를 이용할 수 있습니다.

---

## 분석 결과 예시

분석이 완료되면 다음과 같은 요약 정보가 자동으로 생성됩니다.

- 총 업로드 이미지 수
- 총 검출 결함 수
- 가장 많이 검출된 결함 class
- 가장 적게 검출된 결함 class
- 평균 confidence가 가장 낮은 class → 데이터 보강 또는 추가 학습이 필요할 수 있음을 안내
